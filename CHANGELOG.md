# Changelog

## VERSION 4.3.0 (1.12.2 Forge Port)
- Ported Wildfire's Female Gender Mod to Minecraft 1.12.2 (Forge) using RetroFuturaGradle.
- Retained full player model customization, breast physics (bounce & floppy sliders), and wardrobe GUI screens.
- Added Metamorph and Blockbuster mod compatibility (`BreastMorph` and custom GUI morph editor).
- Preserved multi-language support (English, Russian, French, German, Spanish, Dutch, Czech, Korean, Chinese, Tatar, Pirate Speak).
- Repository: https://github.com/azubangithub/LegacyFemaleGenderMod-1.12.2
- Issues: https://github.com/azubangithub/LegacyFemaleGenderMod-1.12.2/issues
