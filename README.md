# LFGM (Legacy Female Gender Mod)

[![GitHub Issues](https://img.shields.io/github/issues/azubangithub/LegacyFemaleGenderMod-1.12.2)](https://github.com/azubangithub/LegacyFemaleGenderMod-1.12.2/issues)

**LFGM** is an unofficial port of Wildfire's Female Gender Mod to **Minecraft 1.12.2 (Forge)**.  
It adds customization options to the player model by adding breasts and realistic physics for a more feminine appearance.

This mod is primarily client-sided, but settings are automatically synced with other connected players when the mod is also installed on the server.

## Links

- **Repository**: [GitHub](https://github.com/azubangithub/LegacyFemaleGenderMod-1.12.2)
- **Issue Tracker**: [GitHub Issues](https://github.com/azubangithub/LegacyFemaleGenderMod-1.12.2/issues)
- **Original Mod**: [Wildfire's Female Gender Mod](https://modrinth.com/mod/female-gender)

## Features

- Full player customization (gender, breast size, cleavage, physics).
- Wardrobe and character settings GUI.
- Physics sliders (bounce intensity, momentum/floppiness).
- Hurt sound toggles and custom female damage sound effects.
- Armor physics configuration via resource packs.
- Optional compatibility with **Metamorph** and **Blockbuster** mods (breast morph support).

## Default Controls

- **G** - Open Customization Settings
